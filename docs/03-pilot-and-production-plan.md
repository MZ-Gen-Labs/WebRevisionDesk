# Web Revision Desk Pilot・実運用移行計画

- ステータス: Draft 1.1
- 作成日: 2026-09-17
- 更新日: 2026-09-18
- 前提: PoC主要機能の動作確認完了

## 1. PoC確認結果

以下は実装済みで、基本動作を確認済みである。

- 案件フォルダとページ一覧を中心とした取得・編集。SingleFile HTMLは案件設定内の補助取り込みとして対応
- CSS、CSS内 `@import`、画像を含む主要レイアウトの再現
- テキスト、リンク、画像、alt、classの編集
- 要素の削除、前後移動、既存ブロックの複製
- 修正前・修正後の保持、変更箇所の画面確認、読込時点へのリセット
- 修正後HTML、操作差分HTML、赤入れHTMLの保存
- 案件フォルダ管理、一括取得、公開ページ更新確認、バックアップ付き更新
- 操作単位のUndo/Redoと共有用ZIP出力
- 3段階の作業案内、対象別編集メニュー、詳細設定、未保存表示

技術方式は `iframe + contenteditable + DOM API` を継続採用する。現時点ではVvvebJsへ移行する必要性は低い。

## 2. Pilotの目的

実際の修正依頼業務で試し、対応可能なページ範囲、作業時間削減、指示の伝わりやすさ、安全な運用方法を確定する。

## 3. 優先順位

### P0: Pilot開始前に必要

1. 案件一式の保存（実装済み）
   - original.html、modified.html、差分HTML、赤入れHTMLを同じ案件として出力する
   - 対象URL、ページ名、作成日時を含む
2. Undo/Redo（実装済み）
   - 直前操作を段階的に戻す・やり直す
   - 現在の「元に戻す」は全変更リセットとして名称を分ける
3. エラー表示
   - 取得できなかったCSS・画像・フォントを一覧化する
   - 取得失敗と編集失敗を区別する
4. 取得・保存テスト
   - 実ページ5〜10件で原本、取得結果、保存結果を比較する
   - 純粋ロジック、主要編集フロー、更新ZIPのハッシュ拒否は自動テスト実装済み
   - Windows完全版ZIPの展開・起動スモークテストはRelease CIへ実装済み
5. 利用上の注意
   - 社外秘・個人情報を含むページの扱い
   - 取得権限と著作権を持つページだけを対象とする

### P1: Pilot中に改善

1. 案件フォルダによる複数ページ保存・作業再開（初期実装済み）
2. 基準URL配下の再帰検索、重複除外、未取得ページから取得ブラウザを開く操作（実装済み）
3. 複数選択、一括取得、公開ページ更新確認、バックアップ付き更新（実装済み）
4. 変更履歴の編集、並べ替え、注記追加
5. 選択要素の階層表示と選択しやすさの改善
6. 複製したブロック内のID重複警告
7. ページ取得の未取得リソース表示
8. 修正指示ページの印刷・PDF向けレイアウト
9. 初心者と習熟者の双方による操作性評価（迷った箇所、完了までの時間、詳細設定の発見性）

### P2: 正式導入時に判断

1. WindowsポータブルZIPの配布・自動更新運用を正式化（初期実装済み）
2. 複数ページ案件の選択エクスポート
3. テンプレート化したブロック追加
4. 承認フロー、共同編集、CMS連携

## 4. 互換性の境界

次の内容は静的な取得・編集との相性が悪く、保証対象外または個別検証とする。

- canvas描画、動画プレイヤー、地図等の動的コンテンツ
- Shadow DOM、クロスオリジンiframe内部
- JavaScript実行後も継続的に更新される画面
- ログイン期限やアクセス制御で取得できないリソース
- CSS疑似要素内の文言、CSS背景画像の専用編集
- 保存時点より後の操作で初めて読み込まれる遅延コンテンツ

## 5. Pilot評価指標

認証付きサイトでは、ログイン待機から完了までの操作と、ブラウザ再起動後の一括取得への認証引き継ぎを実サイトで確認する。期限切れの自動判定と認証情報消去専用UIは未実装。

各案件で次を記録する。

| 指標 | 測定内容 |
|---|---|
| 作成時間 | 従来の指示書と本ツールの所要時間 |
| 再現性 | 重大なレイアウト崩れの有無 |
| 網羅性 | 意図した変更が差分へすべて出たか |
| 理解度 | 実装担当者が追加確認なしで理解できたか |
| 手戻り | 修正漏れ、誤解、再依頼の件数 |
| 操作性 | 利用者が迷った操作と所要時間 |

## 6. Pilot合格基準案

- 対象ページの80%以上で重大なレイアウト崩れがない
- 主要な変更操作の95%以上が差分へ記録される
- 修正指示作成時間が従来比30%以上短縮される
- 実装担当者による変更箇所の見落としが発生しない
- 重大なセキュリティ事故またはデータ消失がない

## 7. 推奨する次の実装単位

「共有用ファイル一式をZIPで保存」「Undo/Redo」「案件フォルダ管理」「関連ページ検索」「複数ページの一括取得」「公開ページ更新確認」「バックアップ付き更新」「初心者向け操作案内」「Windowsポータブル版の更新確認・切替」は実装済み。次は複数ページの選択ZIP出力、実ページ互換性試験、取得できなかったリソースの可視化、初心者を含むPilot操作評価を行う。
