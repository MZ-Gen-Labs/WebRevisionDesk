# Contributing

Thank you for your interest in Web Revision Desk.

1. Open an issue describing the proposed fix or improvement.
2. Create a focused branch from `main`.
3. Run `npm ci`, `npx playwright install chromium`, `npm test`, and `npm audit --audit-level=high` before submitting.
4. Submit a pull request with the reason for the change and verification steps.

By submitting a contribution, you agree that it is licensed under the Apache License 2.0.
